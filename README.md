# 할 일 카드

할 일을 카드로 만들고, 카드의 상태를 "할 일 / 진행 중 / 완료" 중에서 바꾸는 웹앱입니다.

## 현재 상태

요구사항과 설계를 확정했고, 구현 중입니다. 화면(`frontend/`)과 서버(`backend/`)를 이어, 저장된 카드가 상태별 칸에 보이고, 카드를 만들 수 있습니다. 새로고침하거나 브라우저를 다시 열어도 카드가 남아 있고, 좁은 화면에서는 세 칸이 세로로 쌓입니다. 카드가 없는 칸에는 "카드 없음"이 보입니다. 카드의 상태 버튼이나 끌어다 놓기(컴퓨터만)로 상태를 바꿀 수 있습니다. 카드 안에서 내용을 고치거나, "정말 지울까요?"를 확인한 뒤 지울 수 있습니다. 만들기, 수정, 상태 바꾸기, 삭제가 실패하면 그 자리에 안내 문구가 보입니다. 화면 디자인(색, 글자, 여백)은 아직 없습니다. 작업별 진행 상황은 [PLAN.md](PLAN.md) "작업 목록"에 있습니다.

- 앱 안에 AI 기능은 넣지 않습니다.

## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들었는지 확인합니다.

## 실행 방법

아직 미정입니다. 앱을 만든 뒤 여기에 적습니다.

## 확인과 기록

- 무언가를 만들거나 바꾸면 "현재 상태"를 그에 맞게 고칩니다.
- 새 문서를 만들면 "프로젝트 문서" 표에 추가합니다. PLAN.md의 "참고 문서" 표와 AGENTS.md의 "문서 역할" 표도 함께 고칩니다.
- 실행 방법이 정해지면 "실행 방법"을 채웁니다.

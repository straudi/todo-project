# 할 일 카드

할 일을 카드로 만들고, 카드의 상태를 "할 일 / 진행 중 / 완료" 중에서 바꾸는 웹앱입니다.

## 현재 상태

만들기 전입니다. 지금은 문서(README.md, AGENTS.md, DECISIONS.md, PLAN.md, PRD.md)만 있습니다.

- 앱 안에 AI 기능은 넣지 않습니다.

## 프로젝트 문서

| 문서 | 내용 |
| --- | --- |
| [README.md](README.md) | 프로젝트 소개, 현재 상태, 시작·실행 방법 |
| [AGENTS.md](AGENTS.md) | 이 프로젝트에서 일하는 AI의 작업 규칙 |
| [DECISIONS.md](DECISIONS.md) | 사람이 확정한 결정 기록 |
| [PLAN.md](PLAN.md) | 이번 목표와 범위, 작업 목록, 실제 검증 결과, 남은 문제와 다음 행동 |
| [PRD.md](PRD.md) | 만들 기능과 이번에 만들지 않을 기능 |

## 시작 방법

1. 이 폴더를 엽니다.
2. 이 README.md를 처음부터 끝까지 읽습니다.
3. "현재 상태"에서 지금 어디까지 만들었는지 확인합니다.

## 실행 방법

아직 미정입니다. 앱을 만든 뒤 여기에 적습니다.

## 확인과 기록

- 무언가를 만들거나 바꾸면 "현재 상태"를 그에 맞게 고칩니다.
- 새 문서를 만들면 "프로젝트 문서" 표에 추가합니다. PLAN.md의 "참고 문서" 표와 AGENTS.md의 "문서 역할" 표도 함께 고칩니다.
- 실행 방법이 정해지면 "실행 방법"을 채웁니다.

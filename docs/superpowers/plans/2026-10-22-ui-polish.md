# 화면 다듬기 (UI polish) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 할 일 카드 앱의 모양을 "또렷한 편집형"으로 바꾸고, 머리 영역(앱 제목, 새 카드, 요약 줄)과 만들기 창 제목을 더한다. 기능과 동작은 바꾸지 않는다.

**Architecture:** 색·모양 값은 `frontend/src/index.css`의 변수에 모여 있으므로 변수와 규칙을 바꿔 갈아입힌다. 머리 영역은 새 부품 `BoardHeader.tsx` 하나로 만들고, 칸별 개수는 `App.tsx`가 한 번 세어 칸 머리와 머리 영역에 함께 넘긴다. 문서(SCREEN-SPEC, TEST-PLAN, DESIGN)는 그 내용을 쓰는 작업 안에서 함께 고친다.

**Tech Stack:** React 19 + TypeScript (Vite), lucide-react, Playwright (설치된 Chrome), pytest. 새로 설치하는 것은 없다.

**Spec:** [docs/superpowers/specs/2026-10-20-ui-polish-design.md](../specs/2026-10-20-ui-polish-design.md)

## Global Constraints

- 기능 F-01 ~ F-08, SCREEN-SPEC의 동작·문구·버튼 순서는 바꾸지 않는다. 기존 테스트 파일(`e2e/tests/*.spec.ts`, `backend/tests`)은 고치지 않고 통과해야 한다.
- 새 패키지·도구를 설치하지 않는다 (D-012). 아이콘은 lucide-react만 (D-014). 글꼴은 기기 기본 글꼴. 어두운 화면 없음.
- 만들기 창: 취소 버튼으로만 닫힘, 처리 중 두 버튼 막힘, 실패하면 입력 유지 (D-008). 처리 중 표시는 넣지 않는다.
- 끄는 동안 원래 카드는 `opacity: 0.5` 그대로.
- 색 값은 spec "디자인 계획 (⑤)"의 표를 그대로 쓴다: 바탕 `#FFFFFF`, 먹색 `#111111`, 보조 글자 `#444444`, 주 색 `#FFD43B`, 상태색 `#DEE2E6` / `#74C0FC` / `#8CE99A`, 위험 색 `#B42318`, 문구 바탕 `#FFE3E3`, 메뉴 가리킴 `#FFF3BF`, 누를 수 없음 `#868E96` / `#F1F3F5` / `#ADB5BD`, 카드 없음 점선 `#999999`.
- 글자 대비는 모두 4.5:1 이상 (누를 수 없는 버튼은 예외).
- 화면 문구: 앱 제목 "할 일 카드", 창 제목 "새 카드", 요약 태그 "할 일 N" / "진행 중 N" / "완료 N", 합계 "· 모두 N장", 요약 묶음의 화면 읽기 이름 "상태별 카드 개수".
- AGENTS.md: 파일 삭제, 패키지 설치, 커밋은 매번 따로 승인. 커밋 전에 바뀐 파일 목록을 보여 준다. 승인받은 계획에 있는 파일만 바꾼다.

## Review Focus

1. **카드가 많아 개수가 두세 자리일 때** (예: 할 일 12장): 요약 태그와 큰 개수 숫자가 넘치지 않고, 요약 줄은 다음 줄로 넘어간다. → Task 2 테스트 "개수가 두 자리여도 요약 줄이 맞다", Task 4 375px 테스트
2. **옮기기가 실패했을 때**: 칸이 그대로이므로 요약 숫자도 그대로여야 한다. → Task 2 테스트
3. **다른 기기에서 지운 카드를 건드렸을 때**: 카드가 빠지면 요약 숫자도 줄어야 한다. → Task 2 테스트
4. **띄어쓰기 없는 아주 긴 제목**: 굵은 테두리·그림자로 바뀐 뒤에도 카드가 칸 밖으로 넘치지 않는다. → Task 4 테스트
5. **휴대폰 375px 너비**: 앱 제목, 새 카드, 요약 줄이 가로 스크롤 없이 들어가고 버튼은 44px 이상이다. → Task 4 테스트
